# 无人机烟幕弹防御系统优化算法详细分析

## 3. 优化算法设计（详细版）

### 3.1 多层次优化架构

该算法采用了层次化的"分而治之"优化策略，通过将复杂问题分解为三个连续的优化子问题，实现了计算效率与优化质量的平衡。

#### 3.1.1 第一层：单烟幕弹参数优化

**目标**：对每个无人机-导弹对，寻找最优的单个烟幕弹参数配置。

**数学表达**：
- 定义决策变量向量 $\mathbf{X}_{jk} = (\theta_j, v_j, t_{release}, t_{delay})$
- 优化目标：$\max f_{jk}(\mathbf{X}_{jk})$，其中 $f_{jk}$ 表示无人机 $j$ 对导弹 $k$ 的遮蔽效果函数

**实现方式**：
1. 对每个无人机-导弹对 $(j,k)$，预先构建一个四维参数网格：
   - 飞行方向 $\theta_j \in [0°, 360°]$，共41个离散值
   - 飞行速度 $v_j \in [70, 140]$ m/s，共26个离散值
   - 投放时间 $t_{release} \in [0, 40]$ s，共11个离散值
   - 起爆延迟 $t_{delay} \in [0, 10]$ s，共11个离散值

2. 对网格中的每个点 $\mathbf{X}_{jk}$，评估函数`calculate_effective_shielding_time`计算：
   - 烟幕弹投放点 $\vec{r}_{release} = \vec{r}_{drone,j}(t_{release})$
   - 烟幕弹起爆点 $\vec{r}_{detonation} = \vec{r}_{smoke}(t_{release}+t_{delay})$
   - 有效遮蔽时间区间集合 $I_{jk} = \{[a_1,b_1], [a_2,b_2], ...\}$
   - 总有效遮蔽时长 $T_{jk} = \sum_{[a,b] \in I_{jk}} (b-a)$

3. 选择排名前 $N$ 的解决方案（基于 $T_{jk}$），并保存其参数和遮蔽区间信息

**精细化改进**：
- 在初步优化的基础上，围绕每个顶级解决方案进行局部精细化搜索
- 缩小搜索范围，减小步长，实现参数精确调优
- 例如：方向 $\theta_j$ 的精细化搜索范围为 $[\theta_j-4°, \theta_j+4°]$，步长为0.4°

#### 3.1.2 第二层：单无人机多烟幕弹优化

**目标**：在保证同一无人机参数一致性的前提下，优化每架无人机的烟幕弹组合策略。

**约束条件**：
- 同一无人机的所有烟幕弹必须具有相同的飞行方向 $\theta_j$ 和速度 $v_j$
- 单架无人机最多投放3枚烟幕弹
- 烟幕弹投放时间间隔不小于1秒

**算法流程**：
1. 收集无人机 $j$ 所有可能的方向-速度组合：
   ```python
   direction_speed_options = set()
   for missile_idx in range(3):
       if missile_idx in drone_missile_solutions[drone_idx]:
           for solution in drone_missile_solutions[drone_idx][missile_idx]:
               direction_speed_options.add((solution['direction'], solution['speed']))
   ```

2. 对每个方向-速度组合 $(\theta_j, v_j)$，找出针对各导弹的最佳烟幕弹参数：
   ```python
   for direction, speed in direction_speed_options:
       missile_best_params = {}
       for missile_idx in range(3):
           # 筛选具有相同方向和速度的解决方案
           matching_solutions = [
               s for s in drone_missile_solutions[drone_idx][missile_idx]
               if abs(s['direction'] - direction) < 0.01 and abs(s['speed'] - speed) < 0.01
           ]
           if matching_solutions:
               # 选择有效时长最长的方案
               best_solution = max(matching_solutions, key=lambda x: x['effective_duration'])
               missile_best_params[missile_idx] = {...}
   ```

3. 生成所有可能的烟幕弹组合（考虑约束条件）：
   - 使用`itertools.combinations`生成1到3个目标导弹的所有组合
   - 对每个组合，创建相应的烟幕弹投放计划
   - 调整投放时间，确保间隔至少1秒

#### 3.1.3 第三层：全局防御策略优化

**目标**：组合5架无人机的策略，最大化对3枚导弹的总体防御效果。

**优化问题形式化**：
- 决策空间：$\prod_{j=1}^5 S_j$，其中 $S_j$ 是无人机 $j$ 的所有可能策略集合
- 目标函数：$\max \sum_{i=1}^3 T_i(S_1, S_2, S_3, S_4, S_5)$，其中 $T_i$ 是导弹 $i$ 的有效遮蔽时长

**算法实现**：
1. 使用笛卡尔积生成所有可能的策略组合：
   ```python
   all_drone_combinations = list(product(
       drone_combinations[0],
       drone_combinations[1],
       drone_combinations[2],
       drone_combinations[3],
       drone_combinations[4]
   ))
   ```

2. 对每个策略组合，评估总体防御效果：
   - 合并所有烟幕弹对各导弹的遮蔽区间
   - 计算每个导弹的总有效遮蔽时长
   - 求和得到总体效果度量

3. 并行计算加速：
   ```python
   all_results = Parallel(n_jobs=num_cores)(
       delayed(evaluate_combination)(combo) 
       for combo in tqdm(all_drone_combinations)
   )
   ```

4. 考虑多目标权衡，选择最优策略：
   ```python
   # 确保所有导弹都有非零遮蔽时间
   for best_result in sorted_results:
       if all(t > 0 for t in best_result['times_by_missile']):
           break
   ```

### 3.2 区间合并算法

遮蔽区间的有效合并是评估防御效果的关键步骤。该算法基于贪心策略，实现了高效的时间区间合并，解决了烟幕弹遮蔽效果重叠的问题。

#### 3.2.1 算法原理与数学基础

**问题定义**：
- 输入：时间区间集合 $I = \{[a_1,b_1], [a_2,b_2], ..., [a_n,b_n]\}$，其中 $a_i < b_i$
- 输出：合并后的不重叠区间集合 $I' = \{[a'_1,b'_1], [a'_2,b'_2], ..., [a'_m,b'_m]\}$，使得：
  1. $\cup_{i=1}^n [a_i,b_i] = \cup_{j=1}^m [a'_j,b'_j]$（覆盖范围相同）
  2. $\forall i \neq j, b'_i < a'_j$ 或 $b'_j < a'_i$（无重叠）
  3. $m$ 最小（最少的区间数）

**贪心策略证明**：
- 按起始时间排序：这确保我们总是从最早的区间开始处理
- 贪心合并：如果当前区间与上一个合并区间有重叠，则延展上一个区间
- 该策略是最优的，因为：
  1. 任何最优解都必须按区间起始时间排序
  2. 对于任意相邻重叠区间，合并它们不会减少覆盖范围
  3. 对于任意不重叠区间，保持它们分离是必要的

#### 3.2.2 详细算法步骤

**输入**: 时间区间集合 $I = \{[a_1,b_1], [a_2,b_2], ..., [a_n,b_n]\}$

**输出**: 合并后的不重叠区间集合 $I'$ 和总覆盖时长 $T$

1. **初始化**:
   - 如果 $I$ 为空，返回空集合和 $T=0$
   - 否则，按起始时间对 $I$ 中的区间排序: $sorted\_intervals = sort(I, key=a_i)$
   - 初始化合并区间列表: $merged = [sorted\_intervals[0]]$

2. **区间合并**:
   ```
   for i from 1 to n-1:
       current_interval = sorted_intervals[i]  // 当前处理的区间 [a_i, b_i]
       last_merged = merged[-1]  // 最近合并的区间 [a', b']
       
       if a_i ≤ b':  // 存在重叠
           merged[-1] = [a', max(b', b_i)]  // 更新最近合并区间的终点
       else:  // 无重叠
           merged.append(current_interval)  // 添加新的合并区间
   ```

3. **计算总覆盖时长**:
   ```
   T = 0
   for each [a, b] in merged:
       T = T + (b - a)
   ```

4. **返回**:
   - 合并后的区间集合 $merged$
   - 总覆盖时长 $T$

#### 3.2.3 算法复杂度分析

- **时间复杂度**:
  - 排序: $O(n \log n)$
  - 区间合并: $O(n)$
  - 计算总时长: $O(m)$，其中 $m \leq n$
  - 总体: $O(n \log n)$

- **空间复杂度**:
  - 排序: $O(n)$
  - 合并区间存储: $O(m)$，其中 $m \leq n$
  - 总体: $O(n)$

#### 3.2.4 在防御系统中的应用

1. **单烟幕弹遮蔽区间计算**:
   - 通过时间步进模拟导弹和烟幕云团轨迹
   - 记录有效遮蔽的开始时间 $start\_time$ 和结束时间 $end\_time$
   - 生成区间集合 $I_{jk}$ 表示无人机 $j$ 的烟幕弹对导弹 $k$ 的遮蔽效果

2. **多烟幕弹协同遮蔽效果计算**:
   - 对同一导弹，合并来自所有无人机烟幕弹的遮蔽区间
   ```python
   missile_intervals = {0: [], 1: [], 2: []}
   for drone_idx, drone_solution in enumerate(combo):
       for bomb in drone_solution['bombs']:
           target_missile = bomb['target_missile']
           missile_intervals[target_missile].extend(bomb['intervals'])
   ```

3. **总体防御效果评估**:
   - 对每个导弹，计算合并后的总有效遮蔽时长
   ```python
   missile_times = []
   for missile_idx in range(3):
       total_time = calculate_total_effective_time(missile_intervals[missile_idx])
       missile_times.append(total_time)
   ```

#### 3.2.5 实际示例

考虑导弹M1收到三个烟幕弹的遮蔽效果:
- 烟幕弹1: 区间 $[5.2, 12.7]$
- 烟幕弹2: 区间 $[10.5, 18.3]$
- 烟幕弹3: 区间 $[20.1, 25.9]$

**合并过程**:
1. 排序: $I = \{[5.2, 12.7], [10.5, 18.3], [20.1, 25.9]\}$
2. 初始化: $merged = \{[5.2, 12.7]\}$
3. 处理 $[10.5, 18.3]$:
   - $10.5 \leq 12.7$，存在重叠
   - 更新为 $merged = \{[5.2, 18.3]\}$
4. 处理 $[20.1, 25.9]$:
   - $20.1 > 18.3$，无重叠
   - 添加区间 $merged = \{[5.2, 18.3], [20.1, 25.9]\}$
5. 计算总时长: $T = (18.3 - 5.2) + (25.9 - 20.1) = 13.1 + 5.8 = 18.9$ 秒

这种算法确保了对遮蔽效果的精确评估，避免了重复计算重叠区间的影响，为整体防御策略优化提供了可靠的基础。
