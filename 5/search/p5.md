## 3.组合得优

### 3.1 多层次优化架构

该算法采用了"分而治之"的优化策略，包含三个层次：

1. **单烟幕弹优化**（预计算阶段）：
   - 对每个无人机-导弹对，优化单个烟幕弹的参数
   - 状态空间：$\theta \times v \times t_{release} \times t_{delay}$
   - 通过`get_top_solutions_with_intervals`函数获取最佳参数组合

2. **单无人机策略优化**：
   - 对每架无人机，确保方向和速度一致的情况下，优化烟幕弹组合
   - 使用`itertools.combinations`生成符合约束的所有可能组合
   - 代码实现了创新的方向-速度筛选机制，确保参数一致性

3. **全局防御策略优化**：
   - 组合所有无人机的策略，评估总体防御效果
   - 通过笛卡尔积`product`生成完整的策略空间
   - 采用并行计算加速评估过程

### 3.2 区间合并算法

为评估防御效果，代码实现了高效的时间区间合并算法：

1. 对每个无人机-导弹组合，预计算遮蔽时间区间集合 $I_{jk} = \{[a_1,b_1], [a_2,b_2], ...\}$
2. 对同一导弹的所有区间合并：$I_i = \cup_{j,k} I_{jk}$
3. 通过排序和贪心合并处理区间重叠：
   ```
   合并后区间 = []
   将所有区间按起始时间排序
   初始区间 = 第一个区间
   对剩余每个区间 [a,b]:
       如果 a ≤ 当前区间终点:
           延展当前区间终点 = max(当前区间终点, b)
       否则:
           添加当前区间到结果
           当前区间 = [a,b]
   添加最后一个当前区间
   ```
4. 计算总有效时长 $T_i = \sum_{[a,b] \in I_i} (b-a)$

## 4. 实现特点与创新点

### 4.1 数学优化技巧

1. **预计算与缓存策略**：
   - 提前计算并存储烟幕弹的遮蔽区间，避免重复计算
   - 时间复杂度从 $O(N*M*T)$ 降至 $O(N+M*T)$，其中 $N$ 是组合数量，$M$ 是烟幕弹数量，$T$ 是时间步数

2. **参数一致性约束处理**：
   - 通过集合操作`direction_speed_options = set()`提取唯一的方向-速度组合
   - 对每个方向-速度组合，找到针对各导弹的最佳参数，保证一致性约束

3. **多目标折衷优化**：
   - 代码中的`best_result`选择确保所有导弹都有非零遮蔽时间
   ```python
   for best_result in sorted_results:
       if all(t > 0 for t in best_result['times_by_missile']):

   ```

### 4.2 计算效率优化

1. **高效的区间合并算法**：
   - 时间复杂度为 $O(n\log n)$，其中 $n$ 是区间数量
   - 空间复杂度为 $O(n)$

2. **自适应搜索策略**：
   - 结合已有的精细化搜索结果，减少搜索空间
